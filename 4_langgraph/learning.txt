Langraph, Lang Chain and Lang Smith are the trio of products by Lang Chain


The Lang Chain Ecosystem

LangChain
LangChain is a developer framework for building LLM-powered applications that composes modular pieces like prompts, chains, agents, and memory.
It provides connectors to LLM providers, vector stores, and data sources, plus utilities for prompt templates, caching, and retrieval-augmented generation (RAG).
Use it to assemble reusable pipelines (chains) or agent workflows without reimplementing core plumbing for embeddings, retrieval, and orchestration.
It's language-agnostic (Python/JS) and popular for prototyping and production LLM apps.

LangGraph
LangGraph is their core offering.
LangGraph is actually indepedent of LangChain, while working with LangGraph,
you can use LangChain code to call LLMS. You can use any framework for calling LLMs.
LangGraph is all about a platform that focuses on stability, resiliency, and
repeatability. It's an abstraction layer that allows you to organize your thinking
around a workflow of different activities that could have feedback loop. It allows you to have
all this in a repeatable, easily monitoring, stable and a scalable way.

LangSmith
LangSmith is their monitoring tooling. It gives you visibility to your calls,
and your reasoning to quickly debug failures.

Terminology:
Agent workflows are represented as graphs.

State represents the current snapshot of the application.

Nodes are python functions that represent agent logic,
they receive the current state as an input, do something,
and return an updated State.

Edges are python functions that determine which Node to execute based on the State. They
can be conditional or fixed.

Nodes do the work.
Edges choose what to do next.

The Five Steps to the first Graph.
1. Define the State Class - The state is immutable.
2. Start the Graph Builder
3. Create a Node.
4. Create Edges.
5. Compile the Graph.

When you run a graph application, there's two phases.
- It runs some of your code that lays out the graph that defines what it is that you're trying to achieve.
= You initiate it and then your graph runs.
